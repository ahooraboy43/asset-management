همراه من — نسخه ۳ (نمونهٔ محلی با آماده‌سازی دیتابیس)

نصب:
1) از پوشهٔ فعلی سایت و هر دادهٔ مهم پشتیبان بگیرید.
2) ZIP را روی کامپیوتر استخراج کنید.
3) محتویات پوشهٔ life-pwa-v3 را در ریشهٔ life.joganic.ir آپلود کنید و فایل‌های هم‌نام را جایگزین کنید.
4) برای نسخهٔ تازهٔ PWA، Service Worker از cache نسخهٔ ۳ استفاده می‌کند. در صورت نمایش نسخهٔ قبلی، صفحه را کامل تازه‌سازی کنید یا PWA را ببندید و دوباره باز کنید.

قابلیت‌های پیاده‌سازی‌شده:
- افزودن و ویرایش دارایی‌ها؛ خودرو با مدل، سال، پلاک، شماره شاسی و کیلومتر.
- انواع دیگر دارایی‌ها.
- تعریف عملیات بر اساس تاریخ، کیلومتر یا هر دو، فاصلهٔ تکرار و وابستگی به عملیات دیگر.
- ثبت سرویس انجام‌شده، تاریخ، کیلومتر، قطعه، هزینه، توضیحات و پیوست کوچک محلی (حداکثر ۲ مگابایت).
- تاریخچهٔ عملیات و جمع هزینه‌ها.
- عملیات عقب‌افتاده بر مبنای تاریخ/کیلومتر.
- بایگانی دارایی به جای حذف سوابق.
- انتقال دادهٔ کلید قدیمی hamrah-man-v1 به نسخهٔ جدید بدون پاک‌کردن کلید قدیمی.
- خروجی و بازیابی JSON برای پشتیبان‌گیری.

محدودیت‌های مهم:
- این نسخه هنوز local-first است: اطلاعات هر مرورگر/دستگاه جداگانه است و خودکار بین دستگاه‌ها همگام نمی‌شود.
- اعلان سیستم‌عامل/Push و ورود کاربران فعال نشده‌اند.
- پیوست‌ها در مرورگر و داخل JSON ذخیره می‌شوند؛ برای استفادهٔ جدی، باید به ذخیره‌سازی خصوصی سمت سرور منتقل شوند.
- یادآوری کیلومتری فقط با کیلومتر ثبت‌شده به‌روز می‌شود؛ برنامه خودش کیلومتر خودرو را از خودرو نمی‌خواند.
- فایل database/schema.sql ساختار اولیهٔ MariaDB است و به‌صورت خودکار اجرا نمی‌شود. پیش از اجرا، دیتابیس جدید بسازید و بکاپ بگیرید.
- فایل api/config.example.php نمونه است و هیچ رمز یا اطلاعات اتصال واقعی ندارد. برای فعال‌کردن API باید احراز هویت، مجوزهای workspace، اعتبارسنجی، محدودیت درخواست و مدیریت امن پیوست‌ها تکمیل و تست شود.
- از اجرای schema.sql روی دیتابیس موجود حسابداری یا هر دیتابیس دارای داده خودداری کنید؛ برای این پروژه دیتابیس جدا بسازید.
