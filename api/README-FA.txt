API هنوز عمداً فعال نشده است تا بدون ورود امن، کنترل دسترسی و اعتبارسنجی، اطلاعات شخصی روی اینترنت در معرض خطر قرار نگیرد.

برای اتصال آینده:
- دیتابیس جداگانه بسازید؛ دیتابیس acc.joganic.ir یا وردپرس را استفاده نکنید.
- database/schema.sql را فقط در دیتابیس جدید اجرا کنید.
- رمز دیتابیس را در فایل config خارج از web root نگه دارید و هرگز در Git یا فایل ZIP عمومی قرار ندهید.
- API باید از PDO prepared statements، رمز عبور password_hash/password_verify، نشست یا توکن امن، مجوز عضویت workspace، CSRF/CORS مناسب و محدودیت حجم پیوست استفاده کند.
- همگام‌سازی باید با شناسه‌های پایدار و ثبت تغییرات انجام شود؛ هیچ endpoint آماده‌ای در این نسخه داده‌ها را به سرور ارسال نمی‌کند.
