نسخه اصلاح‌شده برای Windows PowerShell

این بسته همان اسکریپت اصلاحات است، با نشانگر UTF-8 برای اینکه متن فارسی در Windows PowerShell قدیمی خراب خوانده نشود.

از ریشه پروژه S:\Projects\Life اجرا کن:
Set-ExecutionPolicy -Scope Process Bypass
.\hamrah-man-png-fix\Apply-HamrahPngFix.ps1

قبل از تغییر فایل‌ها اسکریپت نسخه پشتیبان می‌سازد. اگر خطای دیگری دیدی، کل خطا را بفرست و فعلاً فایل‌های backup را پاک نکن.
